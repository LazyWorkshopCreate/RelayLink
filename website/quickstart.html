02 / 使用说明

从一台 Server，
到第一条可用通道。

Linux Docker 主机是最快的起点。下面保留关键路径；生产部署前请完整阅读安装指南并配置 TLS、网络访问控制与备份。

准备 Linux Docker Engine、Compose v2 与 PowerShell 7，然后在仓库根目录执行：

pwsh ./scripts/start-server-compose.ps1 -AgentServerHost tunnel.example.com

将域名替换为 Agent 实际可达的 DNS 名称或 IP。

打开管理页面并登录，为每台 Agent 创建独立客户端，再下载专属 JSON 配置。

客户端配置含访问密钥，不得共用，也不要提交到仓库。

Windows 使用安装包；Linux 使用 systemd；macOS 使用 launchd。安装时使用刚下载的配置。

Agent 本机状态页默认位于 http://127.0.0.1:18081/。

要连接第二台 Server，在此页面导入另一份单服务端 JSON。

确认客户端在线后创建通道，选择 TCP 或 UDP，填写 Agent 所在内网可达的固定目标主机和端口。

普通通道可配置来源 IP 安全组；Agent 互访则创建访问映射。
