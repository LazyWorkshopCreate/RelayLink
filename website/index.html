01 / 产品介绍

不是另一张网络，
只是那根
可靠的管子。

RelayLink 不做 VPN、P2P 打洞，也不解析业务协议。它只负责转发受控的 TCP 字节流与单播 UDP 报文，让应用继续使用原来的地址、账号、权限和 TLS。

连接模式

云端访问内网目标

云端应用连接 Server 的代理端口，Server 经已认证 Agent 转发到内网目标。

Cloud appServerAgent

安全模型

授权的 Agent 互访

访问方使用本机回环入口；业务流默认端到端 TLS，Server 只中继密文。

明确边界

透明转发，不碰业务数据

  • 不解析 SQL / TDS 等业务协议
  • 不替代目标服务身份认证
  • 不提供 UDP 广播/组播、VPN 或 IP 层组网
!
安全边界要先看清

普通 TCP 字节流与 UDP 报文均经数据隧道转发，普通代理不提供链路加密。敏感业务应启用业务自身 TLS，或部署在受保护的网络链路中；应用层安全组不能替代加密。
