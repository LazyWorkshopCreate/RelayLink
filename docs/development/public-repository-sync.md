## 公开适配

- 产品代码、配置示例、需求、设计及发布说明来自对应 tag。真实部署 IP 改为 RFC 5737 文档地址，内部机器标识替换为通用示例名称。对应大小写测试的示例名称同步替换。
- 网站、源码及下载链接指向公开仓库；历史私有 CI 链接改为明确的来源运行编号，不伪造公开仓库验证结果。
- 不导入依赖私有自托管 runner 和外部密钥的审查工作流。公开仓库保留 GitHub 托管的 CI、Release 和 Pages。
- 不导入工作区中的未跟踪文件、`.local/`、真实配置、私钥或构建产物。

## 验证边界

提交前执行快照文件比对、JSON 解析、网站构建与测试、`git diff --check`、Gitleaks 与部署元数据检查。扫描命中的固定测试秘密与 RFC WebSocket 示例值按文件和内容逐项核实，不把它们认作生产凭据。推送后的跨平台 CI、发行资产和 Pages 结果以公开仓库对应 tag 的 Actions 记录为准。这些检查不表示生产部署或目标机安装验收。
