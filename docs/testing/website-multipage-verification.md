2026-10-05 重构提交 `0a391a4` 已快进合并至本地 main；提交前从暂存区导出独立目录，安装依赖、生成 54 页并通过全部 4 项站点测试，确认重构提交不依赖未提交的 UDP 文件。随后按用户要求在 main 增补 UDP 首页/快速开始说明及四篇内容的站点入口，构建生成 62 页，5 项测试通过。UDP 专项检查覆盖中英文概要、rc.8 兼容性提示、使用指南参数与限制，以及设计/需求 Draft、ADR Proposed 状态。浏览器确认 UDP 文档列表、首页版本提示、指南详情与章节目录可访问。UDP 后端代码不属于本次站点提交。

本地预览只监听 `127.0.0.1:4178`，以 `/RelayLink/` 前缀访问。检查首页、发布列表与详情的桌面布局、列表到详情、对应英文版本、使用说明列表、快速开始折叠、目录和返回入口；窄屏使用 390 × 844 视口，目录转为正文上方，导航固定到底部，正文能够换行。详情直达和刷新使用实际静态 HTML；浏览器未记录控制台错误。关闭 JavaScript 时快速开始四步正文全部显示，由脚本初始化折叠状态。
