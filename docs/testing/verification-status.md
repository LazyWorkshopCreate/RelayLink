2026-09-17 在 WSL Linux `dev_a` 的 .NET 10.0.100 稳定 SDK 上，以 `-p:EnablePeerTlsTests=true -p:SkipAdminWebBuild=true` 显式运行 Agent 互访集成测试，6 项通过、1 项旧 TLS 测试按原设置跳过；单元测试单独运行 15/15 通过。Windows 上先发现 Schannel 不支持从 PEM/PFX 直接使用临时私钥及 TLS `close_notify` 半关闭差异；修复文件私钥运行时导入和 TLS 内业务 EOF 后，以本机 Windows .NET 10 预览 SDK 重跑互访集成测试，6 项通过、1 项旧 TLS 测试跳过，单元测试 15/15 通过。Windows 目标机仍需用稳定运行时实机复验。

互访集成覆盖：双 Agent 外层 TLS 注册、端到端证书固定和访问密钥挑战、128 KiB 随机字节精确回显及半关闭；双通道 16 并发连接、每条 1 MiB 且回包目标标识正确；无映射的已注册客户端和错误 HMAC 证明被拒绝、被访问目标零连接；匿名云端代理端口关闭且 API 不泄漏访问密钥；管理端登录/CSRF 后新增映射自动下发至在线 Agent 并实际连通。并发测试还确认服务端普通业务流量保持 0，互访密文计数各方向大于实际有效载荷（TLS 开销），不混入普通历史采样。前端 TypeScript 构建、3 项组件测试及 Prettier 检查通过。

新增 Agent 自选端口后，Windows 预览版与 Linux 10.0.100 稳定版最终回归均为单元测试 17/17、互访集成 7/7（另 1 项旧 TLS 用例按原设置跳过）；集成包含真实 Agent 进程重启、旧端口占用、新端口连通、服务端状态上报和 Agent loopback 网页只读内容。前端构建、3 项组件测试及格式检查通过。
Windows Server 的 Service 生命周期、端口绑定及证书私钥权限尚未在目标主机执行实机验证。

## 执行前置条件

- Linux 或 Windows 目标机具备受支持的 .NET 10 运行时、有效服务端证书及最小权限服务账号。
- Windows Agent 目标机能够使用 Schannel 验证服务端证书链和名称。
- 云端内网、目标 SQL Server、固定 TCP 端口与安全组规则已经按需求配置。
- 压测环境必须记录 CPU、内存、NIC、运行时补丁、RTT、丢包、SQL 与驱动版本；没有这些条件的数字不得作为容量结论。
