# design.md — RelayLink 介绍演示文稿

风格定位：**极简科技 · 浅色**（未命中学术 / 商务咨询 / 政务三个垂直分支，走通用设计原则 + 本稿原创常量值）。

## 1. 画布与母版

- 画布：**1280 × 720**（16:9）
- 页面 padding：上 20 / 下 20 / 左 64 / 右 64
- 内容页三区（px，从画布顶边算起）：

| 区 | 位置 | 高度 | 内容 |
|---|---|---|---|
| A · 标题块 | 20 – 108 | 88 | 左：章节小标签（13px 强调色，字母间距 1.5）在标题上方 10px；主标题 34px bold 主色；右侧可放一条 3px × 40px 强调色竖条 |
| B · 内容区 | 124 – 648 | 524 | 一切正文、图、卡片、表 |
| C · 页脚条 | 664 – 700 | 36 | 左：`RelayLink · 开源反向 TCP 代理`（14px 中性）；右：`NN / 21`（14px 中性） |

- 高度核算（固定值，不可溢出）：20 + 88 + 16(gap) + 524 + 12(gap) + 36 + 20 = **716 ≤ 720**
- 封面 / 章节扉页 / 结束页使用自定义版式：padding 0，全幅背景；不出现 C 区页码（封面、结束页不显示页码，章节扉页保留右下页码）。

- 背景装饰几何：`opacity: 0.10 ~ 0.18`，仅用主色或强调色

## 4. 密度门禁（本稿声明为"信息密集极简"，覆盖默认值）

- 内容页正文下限 **180 字**（中文，含卡片内文字）；卡片组每卡 ≥ 60 字、合计 ≥ 220 字。
- 常规内容页留白 ≤ 30%；Hero 页 ≤ 38%（留白必须围绕锚点，禁止均匀稀薄）。
- 容器填充率 ≥ 85%；卡片尾部标签条用 `marginTop: 'auto'` 钉底。
- 每页至少 1 个视觉锚点：≥ 44px 的元素，或占 B 区 ≥ 40% 面积的图。
- 焦点留白：锚点四周 ≥ 28px（本稿为高密度版，覆盖默认 40px）。

## 5. 配图系统

- 全篇配图为**线条化 SVG**（架构图、时序图、流程图、抽象几何概念页），不使用摄影 / 插画 / 3D；风格统一：1.5px 描边、圆角 6–10、无渐变填充块。
- L1 主视觉最小占 B 区面积 40%（Hero 页 ≥ 55%）。
- L3 徽标：C 区左侧固定位置，14px 文本徽标 + 6×6 强调色方块，全篇位置一致。
- SVG 图元配色：节点填充 `#FFFFFF` 或 `#EEF2F8`，描边 `#0F172A` / `#DCE3ED`，关键路径 `#2563EB`。

## 7. 组件用法约定

- 一切布局用 `<Box>` + flex；禁止 grid、禁止 `calc()`。
- 文本一律 `<Text>`，换行用 `<br />`，局部强调用 `<span style={{...}}>`。
- 矢量图一律内联 `<svg width={...} height={...} viewBox='...'>`。
- 内容页统一骨架：A 区 header Box（height 88）→ B 区 body Box（height 524）→ C 区 footer Box（height 36）。
- 页脚徽标全篇一致；页码 `NN / 22` 右下角。

## 8. 构建方式

页码不写死在任何地方，`pages.json` 是唯一事实来源。改页顺序或增删页后跑一条命令即可：

```
node sync.mjs add <slug> <位置>      # 插入新页（自动生成占位幻灯片）
node sync.mjs move <slug> <位置>     # 调整页序
node sync.mjs all                    # 重建 PPTX + 插图 + 文章引用 + 设计文档页码
node sync.mjs check                  # 一致性自检
```

`slides/<slug>.slide` 里的页码一律写成 `{{PAGE}} / {{TOTAL}}`，目录页的章节区间写成 `{{CHn_FROM}}–{{CHn_TO}}`，由脚本渲染。
