# ADR-0001：首期采用独立 TCP 数据隧道

状态：Proposed\
日期：2026-09-16

## 背景

RelayLink 需要用 C# 将各地 SQL Server 的固定 TCP 端点提供给云端内网访问。公网只开放一个接入端口，通道配置由服务端维护。

## 建议决定

每 Agent 一条长期控制 TLS 连接，每条业务 TCP 连接对应一条独立 TLS 数据连接，两者连接相同服务端端口。数据连接使用一次性令牌与控制会话绑定，使用 DATA/FIN 帧表达字节及半关闭。

## 备选

- frp / SSH 反向转发：适合网络验证，但需适配本项目 C#、配置下发和界面要求。
- 单 TCP 多路复用：降低连接数量，但增加流控、调度和共享连接故障处理复杂度。

## 后果

单条数据连接故障可隔离，状态与背压容易落实；成本是每条新业务连接增加 TLS 握手、socket 与 NAT 端口消耗。控制会话中断仍按首期设计关闭所属数据连接。容量和跨地域延迟须通过原型测试验证。
