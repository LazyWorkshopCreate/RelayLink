# ADR-0003：流量历史持久化

状态：Accepted\
日期：2026-09-16

## 背景

运行时指标只保存在内存中，服务端重启后无法查看此前的通道流量和连接计数。管理界面需要提供历史统计数据，但不应保存业务载荷、连接端点或身份凭据。

## 决定

服务端按 `history.sampleIntervalSeconds` 为每个已配置的客户端和通道记录聚合快照。快照包含采样时间、上下行累计字节数、已接受连接数、成功打开数和打开失败数；使用 JSON Lines 文件保存，路径由 `history.filePath` 指定，并按 `history.retentionDays` 清理过期样本。

历史读取通过只读的 `/api/v1/history` 提供，可按客户端、通道和时间范围筛选。仪表盘在未登录状态也展示最近 24 小时的汇总，不包含业务载荷。

## 后果

部署服务账号必须具备历史目录的创建、追加和清理权限。JSONL 便于本地排障和备份，但适用于单服务端实例；需要跨实例聚合、复杂报表或长期高频保留时，应另行评估专用指标存储。
