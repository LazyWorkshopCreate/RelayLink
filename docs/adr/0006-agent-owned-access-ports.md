# ADR-0006：Agent 自主管理互访入口端口

状态：Accepted\
日期：2026-09-17

## 背景

此前访问方映射中的 `localPort` 由服务端指定，服务端无法预知访问方机器上的实际端口占用；重启后的冲突必须由管理员修改服务端配置，且管理页面可能显示一个并未成功监听的地址。

## 决定

服务端继续管理映射目标、启停和授权密钥，但不管理访问方本地端口。Agent 从本地配置的端口范围选择可绑定的 IPv4 loopback 端口，按映射 ID 持久化；重启优先复用，冲突时轮换。绑定成功后，Agent 通过已认证控制连接上报当前配置版本下的实际地址。服务端只展示本次会话的上报值，断线或配置版本切换时清空。旧配置的 `localPort` 可以读取以便平滑迁移，但不再下发或生效。

Agent 另提供仅绑定 `127.0.0.1` 的只读状态页，展示当前通道与访问地址，不回显凭据。网页端口属于 Agent 本地基础配置，不属于服务端通道配置。

## 备选

- 服务端扫描/分配端口：不能准确观察远端主机的进程占用，不采用。
- 每次随机端口且不保存：重启后地址频繁变化，不利于本机应用配置，不采用。
- 绑定端口 0 由内核随机选取：无法约束可用范围，不采用。

## 后果

Agent 需要有权在配置目录写入端口状态文件，并能绑定所设范围；本机应用读取 Agent 状态页或服务端当前报告以获知端口。旧服务端/Agent 版本不支持新的状态帧，升级时需保持版本一致。服务端报告是已认证 Agent 的自报状态，不是服务端对远端可达性的探测结果。
