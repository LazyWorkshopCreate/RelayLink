# Agent 本机页的系统工具入口

文档 ID：ADR-0042\
状态：Accepted\
日期：2026-11-18

## 背景

客户端通过操作系统已有的工具连接 Agent 互访入口。本机页提供连接地址和相应的打开方式，由目标服务执行认证。

## 决定

- Agent 本机页显示互访入口，使用 HTTP/HTTPS 链接打开已就绪的 Web 入口。普通 TCP 入口提供 `ssh://` 链接和可复制的 SSH 命令。Windows 可为普通 TCP 入口下载不含凭据的 `.rdp` 文件。UDP 继续提供地址与复制。
- 用户浏览器处理链接和下载，系统工具处理连接、身份认证及证书确认。Agent 服务继续接入并转发配置的互访流量。
- 本机配置修改继续使用 [ADR-0034](0034-agent-local-write-session.md) 定义的写入会话。连接入口从状态接口提供的已就绪映射生成。

## 备选与影响

由服务直接启动桌面程序需要处理各平台服务账号与交互用户的边界。SSH 链接依赖系统登记的处理器，用户也可在终端执行页面提供的命令。Windows 用户需打开下载的 RDP 文件。操作步骤见[安装与使用指南](../operations/installation-and-usage.md#71-从-agent-本机页连接互访入口)。
