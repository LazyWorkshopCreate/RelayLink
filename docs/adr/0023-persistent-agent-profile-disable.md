# Agent 服务端连接项持久化停用

文档 ID：ADR-0023\
状态：Accepted\
日期：2026-09-29

## 背景

原本机页面仅能物理删除服务端连接项。临时停止某项连接若采用删除，会移除配置；重新连接须再次导入 JSON，且可能误用保留的身份状态。

## 决定

每个 Agent 服务端配置项增加可选 `enabled`，缺省为 `true`，兼容既有配置。停用和启用是独立的本机管理操作，不改变通过 JSON 导入新增、修改连接参数的规则。写操作沿用配置版本、受保护的原子持久化、同源和 CSRF 校验。

停用时先保存 `enabled=false`，再停止该项控制会话、重连、业务连接和本机互访入口，保留配置、密钥、端到端身份及端口状态。Agent 重启后不启动停用项。启用时保存 `enabled=true`，再为该项建立连接并按原规则重连。导入修改保留当前启停状态，不接受导入文件更改此状态；删除仍移除配置项。

## 备选

- 删除后重新导入：增加重复配置和身份误用风险。
- 仅在内存中停止连接：重启后会意外重新连接。

## 后果

本机状态 API 和页面须区分停用与暂时离线。停用或启用只影响目标项；现有流在停用时结束，启用后须由业务方重新建立。既有无 `enabled` 字段的配置继续按启用处理。
