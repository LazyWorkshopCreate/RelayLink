# Agent 服务端配置仅通过导入修改

文档 ID：ADR-0022\
状态：Accepted\
日期：2026-09-29

## 背景

Agent 本机页面原允许逐项填写新增服务端的连接参数，已有服务端只能删除后重新新增。逐项输入容易漏填服务端颁发的 TLS 信任材料，也无法安全地替换既有项的注册密钥和端点。

## 决定

本机页面的新增与修改均只接收服务端下载的单服务端新格式 JSON。新增时自动为导入项分配本机唯一的 `profileId`；修改时用户选定现有项，导入文件的 `clientId` 必须与现有身份相同，并保留本机 `profileId`、端到端身份和端口状态。Agent 校验完整配置、配额和版本后原子保存，再仅停止并重启被修改项的运行上下文。保存失败时原运行上下文不变。删除仍独立操作。

## 备选

- 保留逐项编辑：容易与服务端下载配置不一致，且在浏览器中长期保留已输入密钥。
- 删除后新增：会扩大操作窗口，并可能错误复用或丢失原有身份状态。

## 后果

修改会中断该服务端的现有会话与业务连接；其他服务端继续运行。更换 `clientId` 应作为新服务端配置项处理，不通过导入修改复用既有端到端身份。页面只预览非敏感字段，提交或关闭后清空导入内容。
