# ADR-0020：Windows Agent 安装根目录布局

状态：Accepted\
日期：2026-09-29

## 背景

ADR-0019 为整目录替换引入 `{app}\program`，使服务程序多了一层目录。用户明确要求 Agent 程序直接位于 `C:\Program Files\RelayLink\Agent`，配置、身份、端口状态和日志继续位于 `C:\ProgramData\RelayLink\Agent`。

## 决定

- 两种构建的程序均直接安装到 `{app}`，服务注册路径为 `{app}\RelayLink.Agent.exe`。
- 升级预检先停止现有服务。安装器随后清理根目录中已知的 Agent 程序文件、运行时文件和旧版专用的 `program` 子目录，再复制选定模式的完整发布内容。Inno 卸载记录与安装、卸载脚本保留；ProgramData 中的配置和状态不参与清理。
- 构建脚本检查发布目录只含安装器清理规则覆盖的文件。日后如发布内容增加新类型或子目录，必须同步更新清理规则，否则停止打包。
- 旧版指向 `program` 子目录的服务在配置处理成功后改指向根目录。转换或重新配置失败时保持服务停止并显示错误原因。

## 备选

- 继续使用独立 `program` 子目录并整体替换：便于界定程序边界，但不符合用户选定的安装路径。
- 删除整个 `{app}`：会移除 Inno 卸载记录，导致后续卸载和升级记录失效。

## 后果

安装目录不再额外嵌套 `program`。清理规则需要随发布内容维护；构建时的文件覆盖检查防止新增文件在模式切换后静默残留。配置及身份仍与程序分开保存。ADR-0019 的双模式发布继续适用，其程序目录布局由本决定取代。
