# ADR-0009：通道变更撤销既有连接

状态：Accepted\
日期：2026-09-18

## 背景

[ADR-0002](0002-runtime-channel-configuration.md) 允许通道修改、禁用或删除后，已有连接继续使用旧配置。这会让撤销授权、修改目标或调整通道策略无法立即作用于存量连接。

## 决定

管理员保存通道或删除端到端访问入口后，服务端比较更新前后的对应记录；内容相同不关闭连接。配置实际发生变化且保存成功后，服务端按客户端 ID、通道 ID 撤销该通道的待建立和已建立普通代理连接；端到端连接也撤销以该通道为目标的连接。访问方入口删除时，同样撤销该入口的已有连接。入口创建后不可修改，调整时须删除并重建。其他通道和入口的连接不受影响。相同通道配置保存仍沿用既有持久化和快照下发流程。

撤销通过取消相关连接寿命并关闭数据连接完成，不依赖 Agent 是否已收到新快照。新连接由服务端运行时配置和 Agent 确认版本共同约束；正在建立的连接可能因版本切换而失败。已断开的 TCP/数据库事务不能透明恢复或重放，调用方须自行重新连接。

## 备选

- 保留旧连接直到自然结束：无法及时撤销访问，不采纳。
- 每次保存都断开客户端全部连接：相同内容重复保存及其他通道会被无谓影响，不采纳。
- 仅向 Agent 下发撤销命令：控制连接断线时不可靠，服务端仍持有转发 socket，不采纳。

## 后果

编辑显示名、连接上限等任何通道字段也会中断该通道的业务连接；应在维护窗口操作。监听绑定或配置持久化失败不应撤销已有连接。直接手工改磁盘文件仍不热加载，需重启服务。
