## 客户端互访增量

本节是用户后续明确提出的范围，优先于上文“访问方仅在云端内网”“Agent 本地不维护通道以外配置”等首期描述。原有云端内网代理能力保持兼容；互访能力仅限 TCP。

| 编号 | 需求 |
|---|---|
| U10 | 被访问通道可启用“仅授权客户端访问”；启用时必须配置独立的高熵访问密钥，不能继续开放匿名云端代理端口 |
| U11 | 访问方 Agent 可按服务端下发的映射，在本机 `127.0.0.1:端口` 监听，并指定目标客户端 ID、通道 ID 与访问密钥 |
| U12 | 访问方、被访问方的互访配置均在服务端集中管理并下发；Agent 不将映射或访问密钥作为本地配置文件维护 |
| U13 | 两端 Agent 均只主动连接服务端控制与数据端口；服务端只转发互访业务帧，不能将未认证的请求导向被访问方目标；业务流加密模式以后续可选加密需求为准 |

### FR-07 授权互访与端到端保护

- 端到端访问入口只提供从访问方到被访问方的单向接入，监听访问方 Agent 的 IPv4 loopback；拒绝配置 `0.0.0.0`、LAN 地址或公网地址。loopback 上的本机任意进程原则上可连接，因此本机 OS 用户隔离和业务自身鉴权仍需保留。
- 创建入口时只选择目标客户端和目标授权通道；服务端生成入口 ID：`<目标客户端 ID>-<目标通道 ID>`。入口创建后不提供修改操作，调整目标或启停须删除后重建；已有旧 ID 仍可读取和删除。若生成的 ID 已存在，则拒绝重复创建。
- 每条访问方映射只能关联一个明确的目标客户端与通道；服务端检查访问方已认证、映射确属该访问方、目标通道启用且为授权互访模式。仅知道目标 ID 不得建立隧道。
- 被访问方收到连接后再次校验目标通道、调用方身份和独立访问密钥；校验成功前不得连接目标业务 TCP 端点，更不得传递业务字节。错误、缺失、过期或重放凭据必须拒绝。
- 访问密钥至少为密码学安全随机数生成的 32 字节，按通道独立设置；不可用人类口令充当“复杂密钥”。管理 API 的匿名响应、状态/历史接口、日志不暴露密钥。启用授权模式而无合格密钥时配置检查及保存失败。
- 互访配置下发包含访问密钥，因此互访启用时 **Agent↔Server 控制连接 TLS 必须开启**。业务流默认使用 Agent↔Agent 内层 TLS；管理员可按 [REQ-001G](2026-09-22-optional-peer-encryption.md) 对单个互访通道显式关闭，关闭后服务端及数据链路可见明文。独立数据端口不叠加外层 TLS，绑定元数据和一次性令牌均须依赖受信网络防护。
- 访问方必须验证被访问 Agent 的端到端公钥身份。Agent 在认证注册时上报指纹；服务端首次将其固定到客户端配置，不能把同一身份重复放在通道配置中，后续指纹变化不得自动覆盖。创建访问入口前建议带外核对首次固定值；首次登记依赖客户端密钥及控制连接安全，不能当作独立的带外身份认证。证书私钥仅存被访问 Agent 本机，不能出现在服务端配置、下载或控制快照中。证书轮换须通过受保护的显式配置维护完成。
- 既有非授权通道保留原云端内网代理监听和转发语义。切换到授权模式时停止原代理监听；切回时恢复监听。配置保存与 Agent 下发仍按现有版本/确认机制生效；通道真实变化时按 [ADR-0009](../adr/0009-revoke-connections-on-channel-change.md) 断开该通道的存量连接。
- 互访连接沿用全局、每客户端和每通道连接与待建立配额；两个 Agent 任一控制会话断开，相关待建立与活动互访连接须释放。无界排队和无限制握手不允许。

### FR-08 Agent 自主管理访问端口与本机状态页

- 服务端只管理访问映射的目标与授权信息，不决定访问方本地端口。Agent 首次为每条启用映射在本机配置的可用端口范围内选择并绑定端口，持久保存映射 ID 与端口。重启优先复用；若被占用则绑定新端口并更新本地状态。
- Agent 在认证控制会话上报告实际已监听的 `127.0.0.1:端口`；服务端只展示当前会话的报告，不把旧端口当作可用地址，也不接受其他客户端代报。旧服务端配置中的 `localPort` 仅为迁移兼容字段，不再下发或生效。
- Agent 在本机 loopback 提供只读网页，展示当前在线通道、互访目标和实际可用入口；不提供写操作，不展示访问密钥、客户端密钥或证书私钥。网页端口可由 Agent 本地基础配置指定。

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A23 | 首次启动、重启及旧端口被其他进程占用 | 首次选出可用端口；重启复用；冲突后轮换且旧地址不再上报，服务端显示新地址 |
| A24 | 打开 Agent 本机状态页并查询服务端管理列表 | 页面仅本机可访问、只读、无密钥，通道与入口地址和服务端报告一致 |

### FR-09 Windows Agent 安装包

- 提供 win-x64 自包含安装包。首次安装必须选择 Agent JSON；检测到已有安装时，交互向导必须提供“仅更新”和“重新配置”两种方式。仅更新只替换软件文件，保留安装目录外的配置、CA、端到端身份、端口状态与诊断日志；重新配置必须选择新的 Agent JSON，校验后清空 Agent 管理的本地配置、身份、端口状态及诊断日志，再启动服务。静默升级必须显式指定方式，重新配置还须提供 JSON。
- 安装时将配置及启用 TLS 时的信任 CA 复制到受限目录，注册为自动启动的 Windows Service 并立即启动，服务使用该配置连接服务端。升级只允许操作属于同一安装目录的现有服务；不能隐式覆盖其他同名服务。
- 安装成功后在所有用户桌面创建使用系统默认浏览器打开 Agent 本机状态页的快捷方式，地址采用配置中的 `dashboardPort`，未配置时使用默认端口 18081；`dashboardPort` 为 0 时不创建快捷方式。
- 卸载时停止并移除服务及程序；配置、CA、生成的身份与端口状态保留供管理员备份或安全清理。

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A25 | 首次安装或重新配置不选配置、静默安装缺少所需参数、配置无效 | 操作失败；原有配置和状态不因配置校验失败而清空，其他同名服务不被覆盖 |
| A26 | 选择有效配置安装并重启 Windows | 自动启动的服务使用 ProgramData 中配置连接服务端，客户端在管理页显示 Online；卸载后服务消失，敏感状态保留 |
| A27 | 分别使用默认、自定义及关闭的状态页端口安装 | 桌面快捷方式分别指向实际本机地址，或在关闭状态页时不创建；卸载仅移除安装程序生成的快捷方式 |
| A28 | 对已有安装分别选择仅更新和重新配置 | 仅更新保留现有配置、身份、端口状态及诊断日志并重启服务；重新配置使用新 JSON，删除旧配置和本地生成文件，按新状态页端口调整快捷方式并重启服务 |
