## FR-10 独立控制入口与原始数据流（2026-09-18）

- 控制入口只接受注册及其后续控制消息，数据入口只接受已获当前认证会话授权的连接绑定；不允许在数据入口注册或在控制入口绑定数据。
- 普通代理数据连接仅在起始阶段交换 `BindData/BindAccepted`；`TargetReady/Start` 走已认证控制连接。Start 后直接双向复制 TCP 字节，业务数据不再加帧、压缩或改写；单向 EOF 仍须允许反向尾包返回。
- 互访加密模式保留内层 TLS 与应用 EOF 封装；明文模式使用 `Data/Fin/Reset` 直接复制并保留半关闭。两种模式都维持目标侧访问证明，其业务兼容性必须以随机字节、大流量、多通道并发和真实应用实验持续验证。明文安全风险与部署要求见 [ADR-0008](../adr/0008-separated-control-and-raw-data.md)和 [ADR-0016](../adr/0016-optional-peer-traffic-encryption.md)。

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A28 | 分别向控制/数据端口提交错误首帧、未认证或重放绑定 | 全部拒绝，目标零连接；正确控制认证和配置确认后，单次令牌可绑定且不能复用 |
| A29 | 在独立数据端口执行随机双向大流、并发、半关闭及真实 RDP/SQL 对照 | 字节与哈希完整、反向尾包不丢、资源有界；仅本机模拟通过不能代替跨主机 RDP 登录显示与 SQL 应用验收 |
| A30 | 对普通及授权通道重复保存相同配置，再修改、禁用或删除；删除访问入口，并保持另一通道在线 | 相同保存不影响原连接；真实变更后仅受影响通道的待建立与已建立连接及时断开，其他通道继续传输；入口删除仅撤销该入口的连接 |
| A31 | 创建端到端访问入口、重复创建、尝试编辑、删除后重建 | 服务端按目标客户端 ID 与通道 ID 生成入口 ID，重复 ID 拒绝；创建请求不需提供 ID；已有入口不提供编辑接口或操作；删除后重建并下发至 Agent |
| A32 | 普通与互访通道分别传输、重复采样、重启和查询历史 | SQLite 以 UTC 分钟/客户端/通道唯一存储增量；重复采样不重计；互访转发字节可单独辨识并结合通道加密设置解释为密文或明文；重启后历史仍可查 |
| A33 | 旧 JSONL 配置迁移、90 天保留及大范围图表查询 | 原文件保留，SQLite 导入只执行一次；超期窗口被清理；查询范围放大时响应点数受聚合限制 |

## FR-11 审计事件

- 管理登录成功/失败/注销、Agent 控制会话上线/离线、普通代理连接建立/断开、端到端连接建立/断开及相关拒绝均须形成结构化审计事件。建立是业务流可开始传输，不是裸 TCP accept。
- 审计默认使用 SQLite 持久化；日志只含事件元数据、关联 ID、结果/原因、时间和经配置约束的来源地址，不记录密码、密钥、令牌、业务载荷或 SQL 文本。
- 新登录与连接建立须在审计记录确认持久化后才能返回成功；存储故障时不能静默丢事件，应拒绝新建立并告警。崩溃后未闭合连接需可辨认或补记异常结束。仓库内核心实现与测试见[验证状态](../testing/verification-status.md)，生产故障演练和剩余强化项见[审计与流量设计](../design/audit-and-traffic.md)。

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A34 | 成功/失败登录、普通/端到端连接建立和断开、授权拒绝、审计存储故障与进程重启 | 每个逻辑连接具有可关联的起止记录，敏感内容不落库；故障不产生“成功但无起始审计”的连接，重启后能识别未闭合连接 |
| A35 | 已配置多个云端监听端口、端口被其他进程占用后新增通道 | 登录后打开新增表单会填入从 19000 起下一个可绑定端口；跳过已配置的普通通道及服务端端口；保存时再次绑定，冲突不写入配置 |
| A36 | 授权通道先于目标 Agent 上线创建；Agent 首次、重复及更换证书后注册；旧通道级指纹配置加载 | 通道表单无需指纹；认证并确认配置后只在客户端级持久化首次指纹；相同指纹重连成功，变化时拒绝且原值不变；旧通道字段一律拒绝加载、不自动迁移；未登记前不能创建到该客户端的访问入口 |
| A37 | 匿名打开管理页及 `GET /api/v1/clients/{id}/mappings`，随后登录和注销 | 匿名与登录均可在客户端卡片的表格查看入口、实际本机地址、目标和状态；匿名无删除按钮，公开响应无密钥和目标证书指纹；管理写操作仍须登录和 CSRF |
| A38 | 禁用被其他客户端入口引用且有普通/端到端活动连接的客户端，再尝试新连接并重新启用 | 禁用成功且完整配置持久化、其他客户端入口不丢失；相关旧连接和控制会话立即结束，云端监听停止，新认证/业务连接拒绝；重新启用后按原配置恢复 |
| A39 | 登录/未登录打开安全组，添加含单 IP 与 CIDR 的组并绑定普通通道，收紧规则后测试存量及新连接，解除绑定后删除 | 匿名不能读取/维护安全组；登录后可管理且持久化；匹配来源可接入，不匹配来源立即关闭且不发起 Agent Open；收紧规则撤销不再允许的连接；被引用组删除拒绝，解除绑定后可删；无组通道维持任意来源行为 |
| A40 | 匿名点击通道的“建连中 / 转发中”数字；管理员查看普通与端到端连接并断开其中一条；使用错误通道 ID 或缺少 CSRF 重试 | 弹窗显示连接 ID、来源、阶段、建立时间及两个方向的传输字节，匿名只读；列表可刷新并在断开后更新；仅已登录且携带 CSRF 的管理员可断开指定通道的指定连接，不影响其他通道；过期或不匹配的连接 ID 返回 404 |
| A41 | 匿名和管理员分别请求审计日志；按时间、事件类型、客户端筛选并翻页；重启服务端后复查 | 匿名返回 401；管理员仅看到元数据，起止事件通过连接/会话 ID 关联，敏感凭据和业务载荷不落库；SQLite 重启后记录仍可查，缺失结束事件以 `server_restart` 标识；无效范围和过大页大小返回 400 |
