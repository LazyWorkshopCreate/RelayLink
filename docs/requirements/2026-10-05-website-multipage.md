## 背景与范围

用户明确要求先创建分支，再调研并编写文档，完成 website 重构：主页仅保留基本信息，使用说明、发布日志等建立独立列表和详情页。原网站将产品、部署步骤、文档入口与发布动态集中在同一页，导航依赖锚点，发布说明最多展示三个章节。

本需求只调整公开产品网站的信息结构、静态构建和校验。保留 GitHub Pages、现有视觉风格和中英文入口；正文中的产品能力及 Draft/Proposed 状态由原文决定。本次不扩展代理协议、管理端功能或软件发布范围，不增加搜索、评论、CMS 或站点写入接口。Accepted 表示上述重构范围已由用户明确提出，实现证据和待验收事项另见验证记录。

## FR-WEB-01 首页与导航

- 首页保留定位、支持平台、连接模式、主要边界、安全说明及分类入口，移出完整部署步骤、文档目录与发布日志正文。
- 全站共用首页、使用、文档、动态导航、品牌和语言入口；当前栏目可识别。
- 原首页 `#guide`、`#docs`、`#updates` 收藏链接在启用 JavaScript 时跳转对应列表；`#product` 保留首页介绍定位。

## FR-WEB-02 使用与文档

- 使用栏目提供快速开始及完整安装指南、Docker、Linux、Windows、macOS 指南的列表与详情页。
- 文档栏目提供原有项目概览、技术设计、日志、互访、多服务端、目录、验证、贡献及文档索引的列表与详情页。
- 2026-10-05 用户进一步要求补充 UDP 站点内容：首页与快速开始同步协议范围，使用栏目加入 UDP 指南，文档栏目加入 UDP 需求、技术设计及架构决策详情。保留 Draft/Proposed 状态，说明现有 rc.8 发布包不含此扩展，不改写历史发布说明。
- Markdown 正文继续以仓库现有文档为唯一维护来源；网站目录只维护标题、摘要、稳定 slug 与源路径，不另存完整副本。
- 详情页提供返回列表、章节目录、仓库原文和同栏目前后文章入口；正文中的代码、表格、列表及图片可阅读，已生成文章之间使用站内链接，其他仓库资源链接原文件。

## FR-WEB-03 发布日志

- 发布列表按版本从新到旧展示版本和简介，每个版本拥有稳定详情地址。
- 中文从 `docs/releases` 构建，英文使用既有翻译文件并补齐原先遗漏章节。详情保留全部章节、条目和末尾限制说明，不截断为摘要。
- 缺少英文版本、章节或条目时构建失败；历史说明中的验证数字属于对应版本，不能当作本次测试结果。

## FR-WEB-04 路径、语言与可用性

- 列表和详情都是独立静态 HTML，可直接访问、刷新和收藏，在 `/RelayLink/` 项目子路径下资源与导航正常。
- 中文位于根目录，英文位于 `/en/`；切换语言保持对应列表或文章。导航、首页、快速开始及发布日志提供英文；尚无完整译文的使用与设计文章明确提示中文原文并标记正文语言。
- 每页提供标题、描述、语言标记、正文跳转入口。无 JavaScript 时核心列表、正文与语言导航仍可使用；JavaScript 只增强折叠、复制和旧锚点迁移。
- 桌面详情使用目录与正文双栏，窄屏改为单栏；长代码及表格在各自区域滚动。
