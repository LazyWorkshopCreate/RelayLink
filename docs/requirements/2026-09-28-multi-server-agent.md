## 背景与目标

当前一个 Agent 实例只使用一组服务端地址和客户端身份。需要让同一 Agent 实例同时注册并连接多个彼此独立的 RelayLink 服务端。每个服务端仍独立管理自己的客户端、通道和访问映射；Agent 只执行对应服务端下发的配置。

“隔离”指各服务端的身份与信任材料、控制会话、配置、业务连接、本机入口、状态和故障处理分别归属，不能跨服务端使用或相互修改。多个服务端不组成集群，也不提供跨服务端转发、配置同步或自动故障切换。

## FR-19 多服务端注册与连接

- 一个 Agent 实例可配置一个或多个服务端，并同时维持各自的控制会话；原有单服务端使用场景继续可用。
- 每个服务端都必须预先创建该 Agent 对应的客户端身份，并使用该服务端单独分配的客户端 ID、密钥、连接端点和 TLS 信任材料完成认证。不同服务端允许使用相同的客户端 ID，但不能据此将两个身份视为同一注册关系。
- 一个服务端认证成功、失败、禁用客户端、断线或重连，只改变该服务端的会话及其业务连接；其他服务端的在线状态和重连流程保持独立。
- 数据隧道只能连接其所属控制会话对应的服务端，绑定令牌、会话标识和授权不得跨服务端复用。
- Agent 本地只保存连接各服务端所需的基础配置与受保护的本机状态；通道、访问映射及访问密钥仍由各自服务端管理并下发，不在 Agent 本地维护。

## FR-20 服务端之间的配置与转发隔离

- Agent 按服务端归属保存和应用已确认的配置快照。某服务端的快照更新、撤销、断线或配置错误，不得覆盖、清空或撤销其他服务端的快照和存量连接。
- 普通通道、授权互访的访问映射、访问密钥和目标身份只在所属服务端内生效。一个服务端不能引用、授权或转发到仅注册在另一服务端的客户端或通道。
- 同一通道 ID 或访问映射 ID 在不同服务端出现时，Agent 仍须按服务端归属区分；统计、诊断和本机状态不能将它们合并。
- 本机互访入口由 Agent 统一绑定到 loopback。多个服务端下发的映射若需要本机端口，不得相互占用同一端口；某个入口端口冲突或绑定失败，只影响该入口及所属服务端的相关映射。
- 与服务端相关的证书信任、Agent 端到端身份及其他持久化状态须按服务端隔离，防止同名客户端或映射互相覆盖。具体存储结构与旧状态迁移由后续设计确定。

## FR-21 故障、资源与可观测性

- 各服务端分别执行心跳、超时、重连和连接清理。服务端停机、认证拒绝、错误配置下发或业务目标故障，不得停止 Agent 进程或中断其他健康服务端的会话和业务流。
- Agent 对每个服务端的待建立连接、活动连接和缓冲占用实施有界资源控制；单个服务端耗尽其配额时，其他服务端仍能接入处于其配额内的新连接。共享主机或 Agent 进程整体故障不属于服务端间故障隔离承诺。
- 本机监控页面及只读状态 API 应能按服务端区分在线状态、客户端身份、通道和访问入口。某服务端离线时不得把该服务端的旧入口显示为可用，也不得隐藏其他在线服务端的入口；响应不泄露任何服务端的密钥、令牌或证书私钥。
- 诊断日志应带可区分的服务端归属信息；不得记录密钥、访问密钥或业务载荷。

## FR-22 本机监控页面管理服务端

- 在 Agent 本机监控页面列出已配置服务端及其连接状态，支持新增和删除服务端连接项；新增后无需重启 Agent 即开始认证和重连，删除后停止该项重连并释放其会话、业务连接和本机互访入口。其他服务端继续运行。
- 新增和修改服务端均只能在页面导入服务端下载的单服务端新格式 JSON，不提供逐项填写或编辑连接参数的表单。新增时为导入项分配本机唯一的 `profileId`；修改时选择现有项，保留其 `profileId` 和端到端身份。导入文件的客户端 ID 必须与被修改项一致；修改成功后仅该项重连，其他服务端继续运行。
- 已注册服务端可在本机页面停用和重新启用，无需导入 JSON。停用须停止该项重连并断开控制会话、业务连接及本机互访入口；配置、密钥、端到端身份和端口状态保留。重新启用后仅该项恢复连接和重连；其他项不受影响。停用状态须持久化，Agent 重启后不得自行连回。修改停用项的配置仍保持停用，直到明确启用。
- 导入文件包含该服务端颁发的客户端 ID、注册密钥、端点和 TLS 信任材料；每项独立校验。页面、状态 API、列表、日志和错误响应均不得查看、回显或下载已保存的注册密钥。导入的密钥只用于本次提交，提交或关闭后清空；不提供“显示已有密钥”或读取完整配置的接口。
- 本机监控页面仅监听 `127.0.0.1`，配置项新增、修改、停用、启用和删除均不要求设置管理密码或登录；状态仍可直接查看。写请求须校验本机来源和 CSRF 令牌，防止其他网页通过跨站请求伪造修改配置；配置文件仍由操作系统权限保护。
- 删除只解除 Agent 本机到该服务端的连接，不删除远端服务端中的客户端或通道配置；页面应明确提示需要在远端另行禁用或删除客户端才能撤销其注册密钥。
- 允许删除最后一个服务端并保持本机监控页面运行，以便重新添加。非法输入、配置持久化失败或新增连接暂时不可达时，不得破坏现有健康服务端配置与连接；暂时不可达的新项可保持离线并独立重试。

## FR-23 新版安装包配置格式

- 新版 Windows Agent 安装包在首次安装和“重新配置”时只接受、校验并写入多服务端新格式；不得把旧单服务端 JSON 复制到运行配置位置，也不得依赖 Agent 启动后再转换。
- 新版服务端下载的 Agent 配置应为包含一个服务端配置项的新格式，可直接用于首次安装或“重新配置”。旧版服务端下载的单服务端 JSON 必须先由独立转换器生成新格式，再交给新版安装包；安装包对未转换的旧文件应明确报错。
- “仅更新”针对已有安装：保留现有注册密钥及身份状态，在首次启动新 Agent 前运行独立转换器；它不要求重新选择配置，也不按“重新配置”清理状态。

## 兼容与范围

- 现有单服务端部署升级后，应在新 Agent 首次启动前由独立转换器将旧配置及相关身份、端口状态转换为新格式；所有启动方式均须先运行转换器，再启动 Agent。转换成功后 Agent 只读取新格式，不在配置加载、运行状态或页面管理中保留旧格式分支。
- 转换须沿用原客户端密钥、端到端证书和本机端口状态，不强制重装、重新注册或更换服务端固定指纹。转换器对已转换配置重复执行应安全无副作用；转换失败须保留旧配置与旧状态，阻止新 Agent 启动并给出不含密钥的错误。安装包“仅更新”不得清理这些状态。
- 保持现有 TCP、TLS 校验、身份认证、通道由服务端集中管理、半关闭和背压要求。多服务端连接不改变各服务端的管理权限边界。
- 不包含服务端集群、跨服务端通道、共享客户端密钥、自动迁移业务连接、自动故障切换或跨服务端统一管理页面。

## 验收标准

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A61 | 为一个 Agent 配置两个独立服务端，分别创建客户端并下发通道 | Agent 同时在线；分别获取并应用各自快照；通过两个服务端的普通通道并发转发时字节和连接归属正确 |
| A62 | 两个服务端使用相同客户端 ID、通道 ID 和映射 ID，但使用不同密钥与配置 | 两边分别认证与运行；配置、本机状态、端到端身份和持久化状态不混淆或覆盖；凭据或令牌跨服务端使用均被拒绝 |
| A63 | 禁用、断开或错误配置其中一个服务端，并观察另一个服务端的长连接和新连接 | 受影响服务端按自身规则清理并重连或报错；另一服务端控制会话、存量流量和新连接继续工作 |
| A64 | 同时下发多个互访入口，制造本机端口冲突与单服务端连接压力 | 入口端口不重复；冲突只影响对应入口；达到一个服务端的资源限制时，另一服务端在其配额内仍能建立连接 |
| A65 | 查询本机状态页和只读 API，并从旧版单服务端配置升级 | 状态按服务端区分且离线入口不冒充可用；无敏感信息泄露；转换器先完成旧配置与状态迁移，Agent 只读取新格式，原身份和入口状态继续可用 |
| A66 | 从已有单服务端安装执行“仅更新”，在新 Agent 首次启动前运行转换器，再通过本机页面新增第二个服务端 | 转换器先成功且重复运行无副作用；升级重启按原身份注册，固定证书指纹及入口端口保持；页面新增不再触发转换或额外断开原会话；再次重启后两项均恢复；注入转换失败时旧配置与状态保持原样，新 Agent 不启动 |
| A67 | 在本机页面新增、删除服务端，包含删除最后一项及新增不可达服务端 | 变更无需重启；删除仅清理该项会话、连接与入口，不改变其他项或远端记录；最后一项删除后页面仍可用；不可达新项离线重试 |
| A68 | 不取得本机页面会话令牌直接写入、跨站提交、查看页面/API/日志/错误并检查保存的配置 | 缺少本机会话或 CSRF 令牌的写入被拒；跨站请求不能修改配置；无需管理密码；已保存注册密钥不在任何读取响应或日志中，新增输入保存后清空，配置文件仍受操作系统权限保护 |
| A69 | 用新版安装包分别首次安装、重新配置及仅更新；输入新旧两种下载配置 | 新装和重新配置只把新格式写到运行配置位置；未转换旧文件被拒且原安装状态不被清理；新版服务端下载文件可直接安装，旧版文件经独立转换后可安装；仅更新保留并转换既有身份状态 |
| A70 | 在本机页面分别导入新服务端 JSON 与现有服务端的新 JSON，尝试逐项修改、错误客户端 ID 和保存失败 | 页面只提供导入入口；新增自动分配本机唯一 `profileId`；修改仅重连选定项并保留端到端身份及其他服务端连接；错误身份或保存失败不改变旧配置与运行状态；导入密钥不回显 |
| A71 | 停用在线服务端、重启 Agent、导入修改停用项、重新启用；同时保持第二项在线，并注入保存失败 | 被停用项的控制及业务连接和本机入口断开且不重连；重启及导入修改后仍停用；配置、密钥、身份和端口状态保留；重新启用后按原身份连接；第二项持续可用；保存失败不改变原状态 |
