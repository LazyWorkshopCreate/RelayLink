## FR-17 Windows Agent 安装兼容性与可诊断性

- Windows Agent 安装包最低支持 Windows Server 2012 R2 x64；低于该版本或非 x64 系统必须在复制文件、修改配置和注册服务前停止安装。
- 安装向导在欢迎页之后显示独立的依赖检查页，以列表列出操作系统、处理器架构、Microsoft Visual C++ x64 运行库和 .NET 10 ASP.NET Core Runtime x64。通过项显示绿色对勾，失败项显示红色叉；可补装的失败依赖显示可点击的官方下载安装链接。依赖未全部通过时不得继续安装，静默安装也必须执行同一检查并以失败退出。
- Windows Agent 使用 `win-x64` 框架依赖发布，不在安装包内携带 .NET 运行时。目标机必须预装同一主版本的 .NET 10 x64 与 ASP.NET Core 共享框架；只安装基础 .NET Runtime 不满足 Agent 本机状态页的运行依赖。Visual C++ x64 运行库也是目标机前置依赖。
- 服务注册、升级、停止和卸载脚本必须兼容 Windows Server 2012 R2 自带的 Windows PowerShell 4.0，不能依赖 PowerShell 5+ 语法或会破坏带空格参数的旧版原生命令参数传递。服务使用 `LocalService`、自动启动及失败恢复策略。
- 服务创建、配置、启动、停止或删除失败时，安装/卸载必须失败，向导显示具体阶段以及底层返回码或错误原因；禁止吞掉退出码或把部分完成报告为成功。失败后的回滚不得删除 ProgramData 中需保留的配置、身份和诊断日志。
- 安装包默认启用 Inno Setup 详细日志，并将可留存副本写入 `C:\ProgramData\RelayLink\Agent\installer-logs`。日志可以记录安装阶段、检查结果、脚本退出码和错误，但不得记录客户端密钥、CA 内容或完整配置正文。

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A54 | 在 Windows Server 2012 R2 x64、较新 Windows x64、低版本 Windows 和非 x64 环境打开安装包 | 支持环境进入依赖页；不支持环境显示红叉并无法继续；尚未修改程序、配置或服务 |
| A55 | 分别模拟 VC++、.NET 10 或 ASP.NET Core 共享框架缺失和依赖齐全，并执行交互与静默安装 | 页面逐项显示绿色对勾或红叉，失败项可打开官方下载页；任一必需项失败时两种安装方式均失败；仅存在其他 .NET 主版本或只有基础 Runtime 时仍拒绝安装 |
| A56 | 首次安装、更新、重新配置和卸载服务，并注入创建、启动、停止、删除失败 | Server 2012 R2 兼容脚本完成正常生命周期；每个故障均使操作失败并显示阶段、返回码或异常原因，不出现安装成功假象 |
| A57 | 执行成功安装和至少一种失败安装后检查日志 | ProgramData 日志包含时间、依赖结论、安装阶段与失败原因，不含客户端密钥、CA 正文或完整 Agent JSON |
