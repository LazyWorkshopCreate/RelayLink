## FR-14 客户端删除与标签筛选

- 客户端删除属于管理员写操作，必须经过管理会话与 CSRF 校验，并在页面二次确认；匿名用户只能查看，不显示删除操作。
- 删除客户端须停止其全部普通通道监听，撤销该客户端作为访问方或目标方参与的待建立及已建立连接，关闭控制会话，并删除对应的服务端客户端配置文件。该客户端自身的通道和端到端访问入口随配置文件一并删除。
- 若其他客户端仍有端到端访问入口引用待删除客户端，服务端必须拒绝删除并明确提示先删除引用入口，不能留下无法通过完整配置校验的悬空引用。
- 删除客户端不清理既有流量历史和审计事件；这些记录继续使用原客户端 ID 作为历史标识。
- 客户端和通道 tag 由管理员手动输入，可设置一个或多个。管理端使用逗号分隔输入；保存时去除首尾空白并按不区分大小写的方式去重。
- 每个客户端或通道最多保存 32 个 tag，每个 tag 长度为 1～64 个字符，不允许控制字符。公开列表与管理台聚合快照可以返回 tag，但不得因此返回密钥或其他敏感字段。
- 页面分别提供客户端 tag 和通道 tag 筛选。输入多个 tag 时采用“同时包含全部 tag”的匹配规则；通道 tag 筛选只展示匹配通道，并隐藏没有任何匹配通道的客户端。
- tag 只用于列表展示与筛选，不参与 Agent 配置快照、配置摘要、认证、授权、安全组、监听、路由、配额或转发判断。仅修改 tag 不得撤销存量连接，也不得向 Agent 发送配置更新。

## 验收标准

| 编号 | 操作 | 通过条件 |
|---|---|---|
| A46 | 管理员删除一个未被其他入口引用的离线或在线客户端 | 对应客户端文件和运行时条目消失；监听停止，控制会话及相关连接结束；匿名或缺少 CSRF 的删除请求被拒绝；历史流量和审计记录保留 |
| A47 | 删除仍被其他客户端端到端访问入口引用的客户端 | 删除被拒绝并返回明确错误；目标客户端、引用入口及所有配置文件保持不变；删除引用入口后可再次删除客户端 |
| A48 | 分别为客户端和通道保存一个、多个、重复及非法 tag，并组合筛选；仅修改 tag 时保持活动连接 | 合法 tag 规范化并持久化；重复值去重，超数量、超长度或含控制字符的值被拒绝；多 tag 使用全匹配规则；通道列表按 tag 收窄；Agent 配置版本、监听和活动连接不受影响 |
