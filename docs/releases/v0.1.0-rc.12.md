# RelayLink v0.1.0-rc.12

这是在 v0.1.0-rc.11 之后收紧 Agent 本机写入、管理登录锁定、配置推送和运行时故障处理的候选版本。回环管理页的只读状态仍匿名，变更接口需要本地令牌；管理入口按设计仍是明文 HTTP。

## 主要更新

- Agent 回环页仍不设密码。只读状态保持匿名。变更 /api/v2/admin/* 必须携带请求头 X-RelayLink-Local-Token。令牌保存在 agent.json 旁的 local-management.token：Unix 为 0600，Windows 的 DACL 限于当前身份、SYSTEM 和 Administrators。导入 useTls=false 时还必须提交 confirmInsecureTransport=CONNECT_WITHOUT_TLS。成功的新增、更新、删除和启用或停用写入 Agent 文件日志，内容为配置项标识、主机、端口、useTls 和客户端标识，不含密钥或令牌。启用或停用记录的是持有变更锁时已经持久化的结果。
- 管理登录锁定改为按直接连接地址和用户名计数，同一组合五次失败后锁定。同一地址另有 20 次的合计上限。状态表满时返回 503，并带 Retry-After。未过期历史仍不淘汰。不读取转发头。
- 客户端文件和监听已经更新之后，若配置推送在写出任何帧字节之前失败，接口返回 200 或 201，且 pushedToAgent=false，控制会话保持。帧写入或刷新开始后失败则关闭该会话，因为字节流可能已经失步。已保存的文件不回滚。
- PeerOpen 与 PeerOpenGranted 携带 setupTimeoutMilliseconds，值为 openTimeoutSeconds 与目标通道 targetConnectTimeoutSeconds 之和。v3 和 v4 帧保留该字段。当前 Agent 在帧版本为 3 或 4 时也采用该值，包括长于 20 秒的预算。更早发布的 Agent 忽略未知 JSON，仍使用内置的 20 秒上限。
- Agent 的 ApplyConfiguration 在停止或创建监听之前校验每一条出站映射。
- 心跳时间与 RTT 以同一份不可变快照发布。失败的 TryRegister 会放弃尚未使用的会话。
- 代理接受循环对可恢复的套接字错误最多重试三次，耗尽后记日志并使 /health/ready 降级。单次可恢复错误的重试不会清除就绪。失败的监听在下一次成功应用配置时被替换，/health/ready 恢复为 200。
- 每个会话在配额检查前对 RequestId 保留两分钟去重窗口。中继 RunAsync 的意外异常会记入日志并完成清理。
- 新建映射使用刚刚从磁盘读入的 LoadedConfiguration。
- 配置访问失败以退出码 2 结束。UnauthorizedAccessException、SecurityException 以及客户端目录访问失败会转为 ConfigurationException。
- 概览、仪表盘、通道列表和映射状态共用同一条通道可用性判定，包括 v3 客户端上的 UDP。
- Agent 在初次注册和配置更新时要求快照的 ClientId 与配置项 ClientId 一致，否则抛出 AgentPermanentException。配置哈希正确也不能单独证明快照属于该配置项。
- FrameWriter 在写出任何字节之前，按读取端的长度规则拒绝无效的 DATA 和 FIN。UDP 监听在调用处理程序之前持有会话；处理程序的同步或异步失败只清理该会话并记日志，不停止监听。UDP 队列仍在满时丢弃最新报文，每次丢弃都增加通道快照和仪表盘快照上的 udpDroppedTotal。Agent 对该配置项的累计值最多每 30 秒记一次日志。

## 升级与兼容性

- NTP1 仍为 v5，JSON schemaVersion 仍为 1。Server 继续同时接受 v3/v4/v5。
- 管理面按设计仍在回环地址上使用明文 HTTP。部分帧截止时间仍是整段时限。匿名只读管理状态保持原设计。
- 调用 Agent 变更接口时，从 local-management.token 读取令牌并设置 X-RelayLink-Local-Token。导入 useTls=false 时同时提交 confirmInsecureTransport=CONNECT_WITHOUT_TLS。
- 早于 setupTimeoutMilliseconds 的 Agent 忽略该字段，互访建立仍限 20 秒。当前 Agent 对 v3 和 v4 帧也使用服务端下发的预算。
- 配置已经落盘而推送在任何帧字节写出前失败时，保存结果为成功且 pushedToAgent=false，文件不回滚。写到一半失败会关闭控制会话。
- 快照 ClientId 与配置项不一致时，Agent 拒绝注册和后续配置更新。
- 普通 TCP、UDP 与 HTTP 仍按 v0.1.0-rc.11 转发。本候选额外在写出前拒绝无效 DATA/FIN，隔离失败的 UDP 会话处理，并把队列丢弃计入 udpDroppedTotal。
