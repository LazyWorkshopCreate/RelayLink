# RelayLink v0.1.0-rc.5

这是面向客户端管理、本机集成和通道安全策略验证的候选版本。

## 主要更新

- 管理页面支持删除离线客户端，并在删除前阻止仍被通道引用的客户端。
- 客户端与通道支持手动维护一个或多个标签，并可在管理列表中按标签筛选。
- Agent 管理 Web 同端口新增仅监听回环地址的只读 HTTP API，供本机第三方软件读取被访问通道和端到端访问入口。
- 仅客户端互访通道新增端到端加密开关，默认启用；关闭时业务流量不再经过内部 TLS，直接在已认证的点对点连接中复制。
- 点对点协议升级到版本 3，握手认证会绑定加密模式，防止两端配置不一致时建立连接。

## 安全与兼容性

- Agent 到 Server 的控制链路和原始数据链路仍使用 TLS；可选项只影响仅客户端互访通道的点对点业务流量。
- 明文点对点模式仍保留双方身份校验、通道授权、会话绑定、资源限制和配置变更撤销。
- 点对点协议版本发生变化，Server 与所有参与互访的 Agent 必须协调升级，旧版 Agent 无法与本版本建立点对点会话。
- 本机只读 API 只绑定 `127.0.0.1`，不提供配置写入能力。

## 验证

- .NET 单元测试 40 项通过，集成测试 29 项通过（包含点对点 TLS 测试）。
- 管理前端 8 项测试通过，生产构建与格式检查通过。
- 覆盖默认加密兼容性、明文流量复制、握手模式校验、配置切换撤销，以及本机只读 API 的响应与访问边界。

## 升级说明

- 建议同时升级 Server 与全部 Agent，避免点对点协议版本不匹配。
- 新建仅客户端互访通道默认启用端到端加密；只有在明确接受链路中业务流量为明文时才关闭该选项。
- 升级前请备份服务端配置、客户端配置、Agent 身份文件以及 SQLite 数据库文件。
