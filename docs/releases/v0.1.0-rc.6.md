# RelayLink v0.1.0-rc.6

这是面向部署体验、安装兼容性和产品文档的候选版本。代理协议与 rc.5 保持一致。

## 主要更新

- 新增 Linux Docker Engine 的 Server Docker Compose 部署方式，包含多阶段镜像构建、首次配置初始化、启动与停止脚本；使用 host 网络以支持动态业务端口。
- Windows Agent 安装包增加系统架构、VC++ 与 .NET 10 ASP.NET Core Runtime 依赖检查，并改为框架依赖交付；安装和服务脚本兼容 Windows PowerShell 4.0。
- 新增中英文产品网站，包含产品介绍、使用指南、文档中心和发布动态；推送版本 tag 时由 GitHub Actions 构建并部署到 GitHub Pages。
- 重整安装与使用文档，按部署方式和操作步骤提供入口。

## 安全与兼容性

- Docker 入门配置仅适合受控环境验证；生产使用或 Agent 互访前必须启用隧道 TLS，并限制宿主机端口的访问来源。
- Docker 配置、客户端密钥和 SQLite 数据保存在本机挂载目录，不进入镜像；停止脚本默认保留这些数据。
- Windows Agent 目标机须预装适用的 VC++ x64 运行库与 .NET 10 ASP.NET Core Runtime x64；不满足依赖时安装器会阻止继续。
- 本版本未更改 rc.5 的点对点协议版本；从更早版本升级时仍需协调 Server 与 Agent。

## 验证与限制

- 中英文站点构建和脚本语法检查在本地通过；Pages 的首次线上部署结果以本 tag 的 Actions 运行为准。
- Docker Compose 配置解析及 Server Release 构建已通过；Linux Docker 主机上的容器启动、持久化和动态通道转发尚未验收。
- Windows Agent 安装包已编译；依赖页、完整安装和卸载流程仍需在干净目标机复验。

## 发布资产

- Windows x64 自包含 Server 压缩包
- Linux x64 Agent 自包含压缩包
- Windows x64 Agent 安装包

候选版本不等同于容量或长期稳定性验收结论；生产部署前仍应在目标网络、权限和运行时环境完成验证。
