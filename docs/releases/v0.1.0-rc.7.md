# RelayLink v0.1.0-rc.7

这是面向 Agent 多服务端连接、本机管理和跨平台交付的候选版本。

## 主要更新

- 一个 Agent 可使用各自独立的客户端密钥、TLS 信任和运行状态，同时连接多个服务端；通道和访问映射仍由所属服务端管理。
- Agent 本机页面改为独立 React 前端。新增和修改连接项只能导入单服务端 JSON；已注册项可停用、重新启用或删除。停用会断开连接并停止重连，配置和身份保留，重启后仍保持停用。
- 新增启动前配置转换器，将旧单服务端配置和身份状态迁移到 `servers[]` 格式。Windows、Linux 和 macOS 的服务启动链已接入转换器。
- Windows Agent 同时提供自包含与依赖 .NET 运行时的程序包和安装包；程序安装在 Agent 根目录，配置与状态保存在 ProgramData。
- 修正 Docker 构建使用的 .NET 10 镜像及 Windows 配置迁移对 UTF-8 BOM 的处理。
- 产品网站增加 Agent 多服务端、JSON 导入及停用/启用的中英文说明；tag 同时触发网站部署和软件包发布。

## 升级与兼容性

- 升级已安装 Agent 时使用保留配置和身份的“仅更新”路径；首次安装和“重新配置”只接受新格式 JSON。重新配置会重置本机受管理状态，不适合保留原端到端身份的升级。
- 旧配置须在新 Agent 启动前由独立转换器处理。转换失败时 Agent 不启动，原配置和身份状态保留供排查与重试。
- 本版本未改变代理线协议。Agent 管理页面仅监听 `127.0.0.1`；写入需要本机页面会话和 CSRF 令牌，页面与只读 API 不返回注册密钥。

## 验证与限制

- 本地通过 63 项 .NET 单元测试及 22 项集成测试；另有 1 项互访 TLS 集成测试在本机默认配置下跳过，发行流水线会启用该项。
- Agent 前端构建、格式检查和独立本机预览通过；停用现有业务流、重新启用后连接恢复、重启保持停用状态已有自动化覆盖。
- Windows 安装包不含代码签名，macOS 包未做 Developer ID 签名与公证。目标环境的安装、网络连通和容量仍需单独验收。
