# RelayLink v0.1.0-rc.2

本版本重点调整隧道结构和 Agent 信任材料的交付方式，并补充真实数据库协议的端到端验收。

## 主要更新

- 控制通道与数据通道完全分离；只有控制通道认证通过后才能建立业务数据连接。
- 普通数据通道完成绑定后使用简单的双向 TCP 流复制，不解析或改写业务协议。
- 完善端到端访问配置、Agent 身份校验、通道变更下发和本机入口端口轮换。
- Agent 下载配置内嵌受信 CA，不再要求用户手工填写目标机器上的 CA 文件路径。
- 改进客户端、通道和端到端访问入口的管理表单及提示信息。
- Windows Agent 安装后创建桌面快捷方式，可使用默认浏览器打开本机只读状态页。
- 新增 SQL Server 与 PostgreSQL 验收脚本；普通代理和双 Agent 端到端加密路径均完成常见查询、联表和事务回滚验证。

## 升级说明

- 控制和数据通道协议在本版本中发生变化，Server 与 Agent 必须一起升级，不应混用 rc.1 与 rc.2 组件。
- 使用管理端重新下载的 Agent 配置可避免沿用旧信任参数。
- 普通代理数据通道不额外加密；敏感业务应启用业务自身 TLS，或部署在受保护的网络链路中。

## 发布资产

- Linux x64 自包含 Server 压缩包
- Windows x64 自包含 Server 压缩包
- Windows x64 Agent 安装包
- `SHA256SUMS` 校验清单

候选版本不等同于容量或长期稳定性验收结论；生产部署前仍应在目标网络、权限和运行时环境完成验证。
