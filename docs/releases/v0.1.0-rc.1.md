# RelayLink v0.1.0-rc.1

这是 RelayLink 的首个候选版本，提供一套可以安装、配置和验证的反向 TCP 代理。Windows Agent 主动连接服务端，因此目标网络不需要开放公网入站端口。

## 主要内容

- 提供 Linux、Windows Server，以及可注册为 Windows Service 的 Windows Agent。
- 支持按客户端独立密钥认证、服务端集中管理客户端和 TCP 通道，并向在线 Agent 下发配置。
- 提供控制连接 TLS、资源限制、连接超时、半关闭和双向流复制等基础传输能力。
- 支持 Agent 之间的授权访问：访问方通过本机 `127.0.0.1` 入口访问另一台 Agent 后方的目标服务。
- 提供管理页面：匿名用户可只读查看运行状态，管理员登录后可维护客户端和通道。
- Windows Agent 安装时必须选择有效配置文件，安装后注册服务并自动启动。
- 建立 Ubuntu/Windows 双平台测试和按版本标签构建 Release 的流水线。

## 发布资产

- Linux x64 自包含 Server 压缩包
- Windows x64 自包含 Server 压缩包
- Windows x64 Agent 安装包
- `SHA256SUMS` 校验清单

这是候选版本，首期仅支持 TCP。部署前请阅读仓库中的安装说明，并使用 `SHA256SUMS` 校验下载文件。
