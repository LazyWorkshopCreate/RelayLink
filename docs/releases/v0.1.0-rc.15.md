# RelayLink v0.1.0-rc.15

本版本完成全仓库 38 项代码审查发现（`CR26-01`–`CR26-38`）的闭环修复，重点修复互访通道长静置 TCP KeepAlive 缺失与 macOS RDP 静置卡死问题，加固自动化管理面 TLS/端口隔离、CLI SPKI 证书固定与跨主体越权防护、传输层与 UDP 稳定性、双端前端与六语言 SDK 一致性，并完善跨平台 CI 与发行流水线。

## 主要更新

- **修复互访通道 KeepAlive 缺失与 RDP 静置卡死（TST-016）**：为服务端 `DataAcceptorService`、`PeerRelayRegistry` 及 Agent `PeerSessionCoordinator.ConnectDataAsync` 的公网数据隧道套接字统一启用 OS 层 `TcpKeepAlive`（30 秒空闲、10 秒间隔、3 次重试）；为互访本机套接字设置 `NoDelay = true`，并在转发写阻塞或故障时中止底层公网隧道、将 `idle.Touch()` 移至写入完成之后，同时将加密互访 4 字节长度头与载荷合并为单次写入以降低小包延迟。
- **自动化管理面隔离、权限与存储加固**：在中间件层将 `Automation`（HTTPS `127.0.0.1:18082`）与 `Dashboard` 严格按端口和 TLS 隔离并补充证书有效期与权限 fail-closed 检查；变更申请持久化设备指纹以拦截跨主体读取或撤销，`DELETE` 接入审计门禁并修复执行异常回滚；配对 `/status` 接入错码计数锁定，补齐证明字段、活跃配对与授权容量上限、缩权 `Satisfies` 校验、防重放/幂等缓存容量上界及私有数据库初始化顺序，并在启动期串行对账与检查 30 天内过期自动化证书。
- **传输、服务端运行时与安全权限强化**：控制口未认证 TLS 握手前启用握手超时与 `TcpKeepAlive`；`TunnelAcceptorService` 与 `ProxyListenerService` 隔离并发准入与高频拒绝审计通道；`FrameWriter` 在写入失败后永久进入 `faulted` 状态并隔离跨会话异常；`FrameReader` 修复帧头后零字节挂起并支持可注入 `TimeProvider` 的确定性部分帧超时控制；Windows `DatagramListener` 禁用 `SIO_UDP_CONNRESET` 并容错可恢复异常；`SecretFilePermissions` 涵盖自动化密钥/数据库并将 Unix `GroupWrite` 目录纳入拒绝范围；`ControlSessionWorker` 改用 `CertificateChainPolicy` 支持中间 CA 链与 30 秒建连超时。
- **CLI、Agent 运维与 Windows 安装向导改进**：`relaylink` CLI 修复 `SHA256(SubjectPublicKeyInfo)` 证书固定与 `auth trust --reset`，在 Windows 改用 DPAPI 加当前用户 ACL、Unix 采用 `0600` 原子写入并严格校验 profile 名称；Agent 本机状态服务端校验 `Sec-Fetch-*`、支持写会话滑动续期、清理空白与配额校验、修复端口分配器回滚与 Windows 文件替换重试；Windows Agent 安装预检为框架依赖包增加机器级 x64 `.NET 10 Runtime` 与 `ASP.NET Core Runtime` 检查。
- **AdminWeb、AgentWeb 与产品网站更新**：`AdminWeb` 拆分为模块化源码，接入 `automationEnabled` 门禁、审批人工缩权控件、CSRF 退出清理与问题详情提取（组件测试 12/12）；`AgentWeb` 支持写会话到期自动续期、控制字符与非 `127.0.0.1` URL 拦截及报错保留（测试 4/4）；产品静态网站关闭协议相对链接、强制外链 `noopener noreferrer` 并同步 HTTP 反向代理、AI 自动化与六语言 SDK 页面。
- **六语言 SDK 与契约一致性提升**：修复 `.NET` `RelayLink.Sdk` 多目标编译（完整产出 `netstandard2.0`、`net8.0`、`net10.0`）及取消超时传播；统一 .NET、TypeScript、Python、Go、Rust、Java SDK 在 UDP 发现、`profileId` 消歧、IPv6、禁代理重定向及跨平台拒绝码映射上的实现，新增 `SdkDataPlaneTests` 与多语言一致性测试套件，并对齐 `contract/` 契约与 `skills/relaylink-admin`。
- **容器部署、运维脚本与仓库文档同步**：Docker 镜像切换为非 root 运行用户（`10001:10001`）并新增 `/health/ready` `HEALTHCHECK` 与受限配置权限；加固 `systemd` 服务沙箱；升级 Windows 服务安装脚本及 4 个本地验收脚本适配多服务端结构；清理历史验证文档中的真实地址信息并同步运维指南与审查记录（`TST-015`、`TST-016`）。
- **CI 与发行流水线健壮性升级**：`ci.yml` 恢复公开仓库及 Fork 的标准 CI 门禁并补齐六语言 SDK、`Skill` 包装与 `AdminWeb` 构建检查。标准 CI 直接报告单元测试失败。`release.yml` 引入独立临时目录下载重试 Action（`download-release-artifact`）与强制覆盖压缩归档；`pages.yml` 消除重复触发并收紧权限；集成测试夹具证书有效期延长至 2 天。

## 升级与兼容性

- **线协议与既有配置兼容**：Server 继续支持 v3–v5 线协议，既有的普通 TCP/UDP 转发、授权互访与目标 Agent HTTP/HTTPS 反向代理配置无需结构调整即可沿用。
- **建议双端同步升级以生效互访 KeepAlive 修复**：互访通道 TCP KeepAlive 分别由访问端 Agent、服务端与被访问端 Agent 在各自的公网数据隧道套接字上启用；同步升级 Server 与相关 Agent 后两端均会发送 `30s / 10s / 3` OS 保活探测。
- **长静置 RDP/SSH 会话建议配置 `tcpIdleTimeoutSeconds`**：OS TCP KeepAlive 探测报文不会重置应用层 `limits.tcpIdleTimeoutSeconds`（缺省仍为 `900` 秒）；如需保持 RDP、SSH 等长时间无界面交互会话不断开，建议将 `server.json` 中 `limits.tcpIdleTimeoutSeconds` 设为 `0` 或按需调大后重启 Server。
- **Unix 数据库目录权限收敛**：从本版本起 `SecretFilePermissions` 除拒绝共享临时目录与他人可写目录外，也会拒绝已存在的同组可写（`GroupWrite`）目录且保持原目录权限不变；Linux 与 macOS 部署请将审计与流量历史目录置于仅服务账号可写的 `0700` 目录。
- **Windows 框架依赖安装前置校验增强**：安装或升级 Windows x64 框架依赖 Agent 安装包时，预检会在停止已有服务前核验机器级 x64 `.NET 10 Runtime` 与 `ASP.NET Core Runtime`；可选自动化管理面 `automation.enabled` 默认仍为 `false`。
