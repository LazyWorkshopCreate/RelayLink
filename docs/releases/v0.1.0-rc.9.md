# RelayLink v0.1.0-rc.9

这是支持普通代理与客户端授权互访 UDP 转发的候选版本，同时更新多页产品网站。本次重新发布纳入 v3 客户端兼容修复；此前同名包不包含修复，请重新下载并核对最新 SHA256SUMS。

## 主要更新

- 普通通道和授权互访支持单播 UDP，按来源地址与端口隔离会话，保留零长度及最大 65507 字节报文边界。
- UDP 通过现有 TCP 数据隧道传输，每来源独立目标 socket；采用有界队列、连接配额和空闲回收，沿用身份校验、安全组与审计。
- 管理页面支持选择 TCP/UDP 和配置 UDP 空闲超时；配置下发、两端状态页和只读 API 展示协议，在线协议切换会重建相关入口。
- UDP socket 的发送缓冲至少设为 128 KiB，修复 macOS 默认缓冲导致大报文发送失败的问题。
- 产品网站拆分为首页、使用说明、文档中心和发布日志的列表与详情页，补齐中英文 UDP 使用、设计和升级说明。

## 升级与兼容性

- NTP1 当前为 v4；Server 同时接受 v3/v4，可先升级 Server，旧 v3 Agent 继续使用普通 TCP 和授权 TCP 互访。响应与配置摘要按会话版本处理，保留新旧 Agent 混合互访；连续更新逐项确认，修复待确认版本被覆盖导致断线的竞态；UDP 只向 v4 下发且要求相关端均为 v4。v1/v2、未知版本和连接内版本切换仍被拒绝，新 Agent 连接旧 Server 未提供自动回退。
- JSON schemaVersion 不变。既有通道缺少 transportProtocol 时默认 TCP；UDP 空闲超时默认 60 秒，可配置为 1–3600 秒。
- Windows 已安装 Agent 使用保留配置与身份的更新方式；升级前备份配置、身份、服务端 SQLite 数据及证书，具体步骤见 [UDP 运维说明](../operations/udp-forwarding.md)。
- 普通 UDP 数据隧道沿用明文数据入口；授权互访默认使用内层 TLS。请按部署要求设置业务安全组、防火墙与链路保护。

## 验证与限制

- UDP 实现及 macOS 修复的 CI 已通过网站、Linux、Windows、macOS Intel 和 Apple Silicon 检查；本次兼容修复本机单元测试 101/101、完整集成测试 59/59 通过，其中 9 项使用未经修改的 rc.8 Agent，覆盖普通 TCP、旧端 UDP 拒绝及新旧端 TLS/明文混合互访与半关闭。互访 TLS 和旧二进制矩阵均启用且无跳过；重建标签将再次执行常规完整 CI。
- UDP 测试覆盖 0/1/32769/65507 字节、来源隔离、空闲回收、安全组与在线 UDP/TCP 切换，并保留既有 TCP 回归。
- 尚未完成跨公网真实 UDP 应用、24 小时容量及目标环境安装验收；不支持广播、组播或 IP 层组网。UDP over TCP 可能产生队头阻塞，不承诺实时延迟。
- Windows 安装包未签名，macOS 包未签名或公证；详细需求、设计及 ADR 仍按各文档标注的评审状态维护。
