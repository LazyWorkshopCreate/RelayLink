# RelayLink v0.1.0-rc.3

这是面向测试和早期部署的候选版本，集中补齐管理、安全、审计和发布能力，并修复真实升级环境中发现的兼容问题。

## 主要更新

- 管理端新增应用层安全组、审计日志、活动连接查看与定向断开。
- 流量历史改为 SQLite 分钟聚合，普通代理与 Agent 互访流量分别统计。
- 端到端身份提升为客户端级证书指纹，支持首次登记、固定和不匹配拒绝。
- 新建普通通道时自动建议可用的服务端监听端口。
- Agent 安装包支持保留本地状态的软件升级和重新配置两种模式。
- 增加可重复执行的本地多场景验收脚本及项目介绍材料。

## 修复

- 修复全新 Windows 计算机运行 Agent 安装包时，Inno Setup 在安装目录初始化前展开 `{app}` 导致的运行时错误。
- Linux Server 改用系统 `libsqlite3.so.0`，避免捆绑 SQLite 在 Ubuntu 20.04 等较旧 glibc 环境无法加载。
- Linux 发布物不再携带未使用且可能不兼容的 `libe_sqlite3.so`。

## 升级说明

- 服务端配置中的端到端证书指纹已从通道级迁移到客户端级；旧通道字段不会继续兼容。
- Server 与全部 Agent 应一起升级。混用旧 Agent 时，配置摘要不一致会导致旧 Agent 无法上线。
- 升级前请备份服务端配置、客户端配置以及 SQLite 数据库文件。

## 发布资产

- Linux x64 自包含 Server 压缩包
- Windows x64 自包含 Server 压缩包
- Windows x64 Agent 安装包
- `SHA256SUMS` 校验清单

候选版本不等同于容量或长期稳定性验收结论；生产部署前仍应在目标网络、权限和运行时环境完成验证。
