# RelayLink v0.1.0-rc.8

这是面向文件日志、连接拒绝诊断和 Windows Agent 配置保存修复的候选版本。

## 主要更新

- Server 与 Agent 统一使用 Serilog 写入结构化 JSONL 文件，记录启动、连接、异常及关联标识；Agent 不再依赖 Windows 事件日志源。
- Information / Warning 日志保留 14 天，按天及单文件 10 MiB 轮转；Error / Critical 日志独立轮转，不按时间或文件数量自动删除。
- 服务端返回明确的控制连接拒绝原因，包括客户端不存在、停用、密钥错误、身份不匹配和重复会话；Agent 记录拒绝代码、原因及连接阶段。日志不包含注册密钥、私钥或业务载荷。
- Server 支持 --log-directory 指定目录，Docker 和 systemd 部署将日志放在 /var/lib/relaylink/logs；Docker 日志使用已有持久化数据卷。
- Windows 安装及更新修复 LocalService 对 agent.json 的修改权限，解决本机页面导入配置时 Unable to save Agent configuration 的问题。
- 补齐日志与诊断需求、技术设计及部署说明，网站同步提供中英文功能介绍。

## 升级与兼容性

- 已安装 Windows Agent 使用“仅更新”保留配置和身份；安装器同时修复旧配置文件权限。Agent 日志位于 C:\ProgramData\RelayLink\Agent\logs。
- 控制协议仍为 v3，拒绝帧新增可选原因字段。Server 和 Agent 均升级后可获得完整原因；旧端保持兼容，但可能只显示通用错误代码。
- 服务端拒绝连接属于 Warning，遵循 14 天保留策略；永久保留仅适用于 Error / Critical。业务诊断轨迹和 SQLite 审计仍使用各自原有策略。
- 常规运行日志应从文件读取；容器标准错误和 systemd journal 主要用于启动及日志系统自身故障。长期保留的错误文件需要运维安排容量监控和归档。

## 验证与限制

- 本地 .NET 解决方案构建通过，82 项单元测试及 30 项集成测试通过；另有 1 项互访 TLS 测试在本机默认配置下跳过，发行流水线会启用。
- 已覆盖日志轮转与保留、拒绝原因传递、重复会话、配置确认拒绝和敏感字段检查；Server 启动错误日志及只校验配置模式完成本地检查。
- Docker Compose 配置解析通过；本次未完成新容器镜像运行及目标环境安装验收。Windows 安装包未签名，macOS 包未签名或公证。
