# RelayLink v0.1.0-rc.4

这是面向测试和跨平台部署的候选版本，新增 Linux 与 macOS Agent 交付，并改进大量客户端场景下的管理页面加载方式。

## 主要更新

- Agent 新增 Linux x64 自包含发布包、systemd 服务模板与独立低权限账号部署说明。
- Agent 新增 macOS Intel（`osx-x64`）和 Apple Silicon（`osx-arm64`）自包含发布包、launchd 服务模板与部署说明。
- 管理页面改为批量获取客户端、通道和访问映射，避免客户端数量较多时产生请求风暴。
- 管理 API 新增聚合配置快照接口，并保留既有单客户端接口的兼容性。
- GitHub Actions 在 Intel 和 Apple Silicon macOS 托管环境中执行原生 Agent 集成及 launchd 生命周期测试。

## 修复

- 修复 macOS 不支持 `EphemeralKeySet` 而无法加载 Agent 身份的问题。
- 修复跨平台发布脚本使用 Windows 路径分隔符导致 macOS 输出目录异常的问题。
- 收紧客户端重新启用测试，等待配置确认后的实际连通性，避免异步上线竞态导致偶发失败。

## 升级说明

- Server 与全部 Agent 建议一起升级，以使用批量管理接口和当前配置协议。
- Linux 与 macOS Agent 应使用专用低权限账号运行；配置和身份文件的访问权限应按部署文档收紧。
- macOS 发布包尚未进行 Developer ID 签名、Apple 公证和 stapling，正式分发前仍需补齐软件信任链。
- 升级前请备份服务端配置、客户端配置、Agent 身份文件以及 SQLite 数据库文件。

## 发布资产

- Linux x64 自包含 Server 压缩包
- Windows x64 自包含 Server 压缩包
- Linux x64 Agent 自包含压缩包
- Windows x64 Agent 安装包
- macOS Intel Agent 自包含压缩包
- macOS Apple Silicon Agent 自包含压缩包
- `SHA256SUMS` 校验清单

候选版本不等同于容量或长期稳定性验收结论；生产部署前仍应在目标网络、权限和运行时环境完成验证。
